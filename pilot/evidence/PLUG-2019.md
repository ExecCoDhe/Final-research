## Context and correction relationship

Issuer: Plug Power Inc. and subsidiaries, consolidated. Reporting interval: 2019-01-01 through 2019-12-31. Statement amounts are USD thousands except explicitly identified share/per-share quantities.

P19: Item 8, Consolidated Statements of Operations, 2019 column, row **Net loss attributable to the Company**: `(85,465)`. This is a loss magnitude of USD 85.465 million; the signed income value is -85,465,000 USD.

P20: Explanatory Note explicitly says the company is restating financial statements for 2019 and 2018. Note 2, **Restatement of Previously Issued Consolidated Financial Statements**, provides a 2019 reconciliation with **As Previously Reported / Cumulative Adjustments / As Restated** columns:

| Row | Previously reported (USD thousands) | Adjustment | Restated |
|---|---:|---:|---:|
| Net loss attributable to the Company | -85,465 | +1,722 | -83,743 |

Arithmetic check: -85,465 + 1,722 = -83,743. The displayed loss magnitude decreases by 1.722 million USD. This is a comparison of reported figures, not a claim of exact unrounded economic quantities.

CF corroborates `us-gaap:NetIncomeLoss`, USD, start 2019-01-01, end 2019-12-31: -85,465,000 under P19 and -83,743,000 under P20. The filing's explicit reconciliation, rather than the mere difference between API values, supports the correction link.

**Important concept distinction:** net loss attributable to common stockholders is a separate row. P20 reports -85,555 thousand for that row. It must not be substituted for net loss attributable to the Company.

## Unchanged control

P19, Consolidated Statements of Cash Flows, 2019 column: **Net cash used in investing activities** is `(14,244)` thousand USD. P20, Note 2's 2019 cash-flow reconciliation shows `(14,244)` as previously reported, no adjustment (dash), and `(14,244)` as restated. The control uses the two independently displayed values; it does not treat every dash in every financial table as zero.

This demonstrates why one amendment/correction event must not automatically alter every line item.
